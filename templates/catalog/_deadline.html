{% load fa %}{% comment %} How long a discount has left. Amber, which on this site means attention: here, time running out (design-language.md, ADR-0016). The server renders the text and sends the seconds beside it, so the badge is right with JavaScript off and ticks with it on. It never sends the deadline itself: a countdown measured against an absolute server time is wrong by however much the visitor's own clock is wrong. It counts hours, minutes and seconds even with days to go (148:44:06), by the owner's choice in design-language.md: a clock that visibly ticks reads as a live offer. At zero static/js/deadlines.js says so and the badge turns neutral, while `_price.html` swaps in the price that follows. The ticking badge is hidden from screen readers. It sits inside a plan's label and a card's link, so it changed their names every second; what is read instead is the day the discount ends, once, and «تخفیف تمام شد» at zero.
